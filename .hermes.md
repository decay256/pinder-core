# Pinder Core Engine Context & Operating Rules

## Scope
- **pinder-core** (`/root/projects/pinder-core`): The C# dating game engine.
- SSOT = `main` branch. Changes are merged via GitHub PRs and consumed by `pinder-web` as a submodule.

## Build & Test Standards
- .NET 8 SDK.
- Verification command: `dotnet test` from the repository root.
- Verification must pass locally before creating PRs.
- Follow engine architecture patterns for character states, dialogue trees, and narrative progression.
