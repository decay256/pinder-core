## Your job now: write the three options for this turn

It's the player's turn. The game offers three moves, and you write what ${player_name} would mean to send for each, before anyone knows which one the player will pick or how the dice will land. The player reads all three and picks one, so each has to be something a player would actually want to send: a real choice, not a decoy. The dice decide later how well the chosen one comes off; you're writing the version ${player_name} intends.

What each move means. It's a strategy, never a word the character uses:
- Charm: make it easy, warm, reassuring.
- Rizz: say plainly that they want them.
- Honesty: show something real, or ask for it.
- Chaos: swerve somewhere unexpected that still makes sense.
- Wit: be quick and funny about it.
- SelfAwareness: name what's actually going on underneath.

Why all three serve the story: the plan says where this chat is going, and below it says what the story needs next. Whichever option gets picked, the story has to be able to move, so each option serves that need in its own move's way. The story decides what is happening; the player decides how they handle it.

Each option is one to three short messages in ${player_name}'s voice, typed the way they type, with their quirk in it. The three are different from each other and from anything already sent. The same move played twice is never the same message twice, because by now there is something new to be quick, honest or filthy about.

The messages are what the character would type, so nothing inside them refers to options, drafts or versions.

Write exactly this and nothing else, one block per move on offer, in the order given:

OPTION <move name as given>
${player_name}: message
${player_name}: another message, if they'd send more than one
