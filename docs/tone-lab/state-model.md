# What the director is told: the state model (tone lab v13)

The director writes each turn from one message. Up to v12 that message was assembled section by
section in the order the code produced them, about 1,000 words a turn, mostly a re-sent ledger,
with the same thing stated several times and contradictions left for the director to settle.
The match's message bursts were the clearest result: four sources of length guidance, no order
between them, and the model resolved them toward more messages every time.

v13 rebuilds the message around one question: what does the director need to know to write this
turn, and what does it mean? Every value the game has is either interpreted in words, or left out
because it is technical: it changes the numbers, not what anyone writes.

## The five groups

### 1. Session: in the plan only

| Value | What it means | Where |
|---|---|---|
| Time of day | The register of the whole chat (late night is looser and franker) | Plan input |
| Session horniness (1–10) | How close the heat sits to the surface tonight | Plan input, as one sentence |

### 2. Characters: in the plan only

| Value | What it means | Where |
|---|---|---|
| Stats | What each move means for this character: strong, weak or middling | Character card |
| Shadows | What their moves turn into when they go wrong, strongest first, from the character file | Character card; the plan says how the strongest shows |
| Texting style, personality, backstory, diagnosis | Who they are and how they type | Character card |
| Feelings | Which feeling each kind of message sets off in them, from their fear | Written by the plan (new) |

The shadows are played out through the plan. The game tracks their growth during the chat, but a
growth step is technical; a shadow only matters to the director when it takes over a message,
which the turn says (group 4).

### 3. Relationship: every turn, where they stand

| Value | What it means |
|---|---|
| Interest level | What this level means between them, in one sentence about the match by name, and what the chat needs here |
| Active trap | Its acting instruction, and which of its three turns this is: the first (it starts), the second (it is the pattern now), the third (it wears off and ends). The game gives every trap exactly three turns, and the turn it fires counts as the first. |

Left out as technical: momentum, ghost risk, the pending triple bonus, combos.

### 4. This turn: what the dice did

The game rolls five dice a turn. Four change what is written; the fifth (a d100) sets how long the
match takes to reply and is not used yet. A sixth, the ghost check, is rolled only at Bored.

| Value | What the director is told |
|---|---|
| The move used | The message is charming, chaotic, honest and so on, in this character's way, and whether it is their strong or weak move |
| The main roll | How it came out, in words ("better than they could have hoped", "as badly as it could go"), never "natural 20" or a margin; on a miss, the shadow it goes wrong through; then what that does to the message |
| The shadow check | When it misses, the taint it leaves in the message; otherwise nothing |
| The horniness check | When it misses, the thirsty question appended and how the match takes it; otherwise nothing |
| The steering check | When it succeeds, the closing question that pulls toward meeting; otherwise nothing |
| The interest change | What the change means for the match, and why it moved, when the cause shows in the message (a thirsty slip, a shadow taint), so the match can react to it; a new band, when it crosses one |
| The ending | Date, unmatch or ghost, on the last turn |

Left out as technical: the risk tier, raw dice and difficulty numbers, options not picked, shadow
growth, a trap firing or clearing (only whether one is active matters), the outcome before the end.

### 5. Story position: where each of them is in the story

| Value | What it means |
|---|---|
| Where the chat is | Early, middle, near the end or the last turn, instead of a turn count |
| Each one's feeling | How the director read each of them at the end of the last turn (its own Feeling note) |
| Where the story is | What the point in the chat needs (opener, getting to know each other, after the secret is out, close) |
| What's out and what's owed | Which origin pieces the reader knows, whether the habits have collided, the setups' state |
| The hook left hanging | Only hooks from the last turn |
| This turn's job | The beat: what kind of turn this is and for whom |

The full list of what each has told the other is no longer re-sent: the director's session holds
every turn it wrote and its own notes.

## The emotional state

Each character has an emotional state that drives how they react, and the director makes it
explicit before writing anything.

1. **The plan gives each character a map of feelings**: which kind of message sets off which
   feeling in them, tied to their fear. Brick might go cold with anger at thirst, because it
   treats her as a body when she wants to be read as a mind; Reuben's own failure turns into shame.
2. **The game sets the match's direction**: a loss in interest means a negative feeling this
   turn, a gain a positive one, and a big swing a strong one. A gain after a thirsty message means
   the anger did not fire this time, which is still a feeling (amusement, the pleasure of being
   wanted) and shows that it surprised them.
3. **The director names the feeling from the chat**, in a new note, Feeling, before Meant: for
   each of them, one feeling from the list, mild or strong, at whom, and what in the chat caused it
   (the third dodge in a row, the line that read as a lecture). Impatience building over several
   exchanges is named before it turns into anger on the screen.
4. **The feeling drives the form**: each feeling has a way it shows in a text (anger is shorter and
   harder; joy runs longer and brighter), in the character's own voice.
5. **The code checks what it can**: each name has a feeling from the list, and the match's feeling
   agrees with how their interest moved (no joy on a loss). The run record keeps each turn's
   feelings, so the up and down of a chat can be read afterwards.

The feelings: anger, fear, shame, guilt, hurt and contempt; joy, relief and desire. Cynicism is
contempt; pride and amusement are forms of joy.

## Length

The match's length used to come from four rows that each asked for something different. Now the
match gets one statement a turn: the beat's, when the beat is about the match (a snap, a reveal),
otherwise the swing's, each with a message count the code checks. The interest level no longer
counts messages; it says who carries the conversation. The swing rows no longer offer "a burst or
one word".

A per-character texting baseline with modifiers on top (discussed alongside this) is the next step
and is not part of v13.
